# TrendPulse — Part 1: Python Foundations

## Overview
TrendPulse analyzes trending YouTube videos across multiple countries using Python.

## Dataset
Countries included:
- United States (US)
- Great Britain (GB)
- India (IN)

Dataset files used:
- USvideos.csv
- GBvideos.csv
- INvideos.csv
- categories.csv

## Requirements
- Python 3
- pandas

Install pandas:
```bash
pip install pandas
```

## How to Run
1. Open `part1_trendpulse.ipynb` in Google Colab.
2. Upload or extract the dataset files.
3. Check the dataset folder path.
4. Run the notebook cells in order.

## Concepts Covered
- Lists, tuples, sets, and dictionaries
- Set intersection and difference
- Counter and slicing
- Nested dictionaries
- Variable scope
- for, range, while, break, and continue
- Functions and conditional statements
- Rule-based video classification

## Data Cleaning
The notebook handles numeric values, Boolean values, and dates. It also tracks parsing failures.

## Results
Results will be updated after running the notebook and checking the output.

## Limitations
The classification uses manually defined rules and is not a machine-learning model.
